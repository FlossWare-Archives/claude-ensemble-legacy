# Claude Ensemble

Claude Ensemble is being redesigned from a clean implementation baseline.

The previous implementation is preserved on the branch
[`archive/pre-restart-2026-10-24`](https://github.com/FlossWare/claude-ensemble/tree/archive/pre-restart-2026-10-24).
